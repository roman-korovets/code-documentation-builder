# Default expand rows

You can specify whether or not rows should be automatically expanded to a specific level when the visual is loaded. This option is set by toggling **Row headers** -> **Default expand rows** on and off and setting the **Expand to level** property to **On**.

Note that if this option is enabled, it will override any custom expansion state set for the rows when a report is saved.
